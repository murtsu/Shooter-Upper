# Legal notes (not legal advice)

**Name.** The game must not use the word "Defender". "Shooter Upper" has NOT
been searched in any trademark register. Before you sell, search EUIPO,
Swedish PRV and USPTO for the name in the games class (Nice class 9 and 41).

**Gameplay.** Rules and mechanics are not copyrightable, but the code, art and
sound of the 1981 arcade game are. This game uses none of them: no copied
sprites, sounds, level layouts or text. All art and sound are generated by code
in this project. Keep it that way.

**Dependencies.** SDL2 is under the zlib license, which allows commercial use
and static or dynamic linking. The Arch package links it dynamically. If you
ship binaries yourself, include the SDL2 license text.

**License.** `LICENSE` is source-available, all rights reserved: readable and
forkable on GitHub, not free to sell or redistribute. For paying customers,
add a short end user agreement in the store listing. The repository
ships no song, so it carries no music rights question. The built-in chiptune is
plain code. If you ever bundle a generated song in a paid release, check
ACE-Step's license for commercial use first.

**Ratings.** No violence against people, no real brands. Check the store's age
rating questionnaire anyway.
